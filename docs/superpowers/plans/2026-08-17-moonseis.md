# MoonSeis 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 构建纯 MoonBit 的地震波形工具包 MoonSeis——miniSEED 3 解析、波形重建、质量检测、STA/LTA 事件检测与 CLI，覆盖阶段 1-4。

**Architecture:** 单模块多子包。`sid`/`time`/`binary` 为基础包；`miniseed3`（解析+CRC）、`encoding`（样本解码）、`record`（装配+迭代）、`trace`（重建+缺口检测）、`quality`（规则+评分）、`signal`（预处理）、`trigger`（STA/LTA）、`formats`（输出）逐层依赖；`cmd/main` 为 CLI。错误用 `suberror ParseError` + typed `raise` + `try/catch`，坏记录不中断整体解析。

**Tech Stack:** MoonBit（moonc 0.10.4，新 `moon.mod` 格式）、`moonbitlang/x`（仅 CLI 读文件）、`moonbitlang/core/json`、`moonbitlang/core/math`。

**模块名占位**：所有 `moon.pkg` import 均用 `"Noverberrain/moonseis/<pkg>"`；最终命名空间由用户提供后在 Task 16 统一替换。

## 已验证的 MoonBit 语法（写代码时严格遵循，避免编译错误）

1. **字节读取**：`Bytes[i]` 返回 `Byte`。小端用位运算：`b[off].to_int() | (b[off + 1].to_int() << 8)`；4 字节转有符号用 `read_uint(b, off).reinterpret_as_int()`。
2. **浮点还原**：`UInt64.reinterpret_as_double()`、`UInt.reinterpret_as_float()`。
3. **字节写入**：`FixedArray[Byte]` 赋值后 `Bytes::from_array(arr)`；`Int.to_byte()`、`UInt` 用 `(v & 0xFF).to_byte()`。
4. **字节切片**：`Bytes::sub` 返回 `BytesView`，不要直接当 Bytes 用。用 `binary` 包的 `slice(raw, start, len)` 助手（内部 `BytesView::make` + `view.at(i)`）。
5. **错误**：`pub(all) suberror ParseError { Variant(..) }` + `impl Show`；函数 `-> T raise ParseError`；`try { ... } catch { Variant(x) => ... }`。
6. **不要用 `?` 解包 Result/Option**：`?` 是 checked-error 传播运算符，不是 Rust 的 try。已知可解包用 `.unwrap()`，需容错用 `match`/`guard`。
7. **可变绑定**：`let mut x = 0`；**`var` 是保留字，禁止使用**。
8. **循环**：`while cond { ... }`（配 `let mut i`）或 `for i = 0; i < n; i = i + 1 { ... }`。
9. **结构体**：数据类用 `pub(all) struct X { f : T }`（字段公开）；带访问器的用 `pub struct` + `pub fn X::f(self)`。
10. **科学计数法**：`1e-9` 非法，必须写 `1.0e-9`。
11. **整数字面量调方法需括号**：`(5).max(3)`、`(7).clamp(min=0, max=5)`；`clamp` 用命名参数。
12. **数学**：`import { "moonbitlang/core/math" }`；用 `@math.sin/cos/floor/PI`；`Double` 有 `.sqrt()/.abs()/.max()/.min()`。
13. **集合**：`Array::make(n, init)`、`.push/.pop(返回 Option，需 ignore)/.concat/.is_empty/.map/.length/.sort_by(cmp)/.sort_by_key(fn)`。排序比较器传 `(T, T) -> Int` 或直接 `sort_by_key`。
14. **Map**：`Map::new()`、`m[k] = v`、`m.contains(k)`、`m.keys()`。
15. **字符串**：`s.length()`、`s[i]` 返回 `Char`、`.has_prefix`、`.substring(start=)`、`.split("_")` 返回 `Iter[StringView]`（`.to_array()` 后再 `.to_owned()` 转 String）、`.trim()`。
16. **类型转换**：`Int.to_double()`、`UInt.to_double()`、`Float.to_double()`、`Int.to_int64()`、`Int64::from_int()`、`Int.to_uint()`、`Int::from_int64()`。`UInt.to_string_radix` 不存在，显示用 `reinterpret_as_int().to_string()`。
17. **CLI**：`cmd/main/moon.pkg` 用 `pkgtype(kind: "executable")`；`@env.args()`；`@fs.read_file_to_bytes(path)` 返回 `Bytes` raise `IOError`，`catch { IOError(msg) => ... }`。
18. **JSON**：`import { "moonbitlang/core/json" }`；`Json::object(map)`、`Json::string(s)`、`Json::number(d)`、`Json::boolean(b)`、`Json::array(arr)`；用 `Map[String, Json]`。
19. **测试**：`test "name" { assert_eq, assert_true, fail }`；`moon test`、`moon test -p <pkg>`；跨包测试类型用 `import { "..." } for "test"`。
20. **`Int16` 样本解码**：直接按字节构建有符号 Int：`let raw = b[off].to_int() | (b[off+1].to_int() << 8); if raw >= 0x8000 { raw - 0x10000 } else { raw }`。

///|
/// Absolute time stored as nanoseconds since the Unix epoch (1970-01-01 UTC).
pub(all) struct Time {
  ns : Int64
} derive(Eq, Debug)

///|
/// Construct from miniSEED header parts (nanos, year, day-of-year, h:m:s).
/// `sec == 60` is a positive leap second, clamped to 59.
pub fn Time::from_header(
  nanos : UInt,
  year : Int,
  doy : Int,
  hour : Int,
  min : Int,
  sec : Int,
) -> Time? {
  if doy < 1 || doy > 366 || hour < 0 || hour > 23 || min < 0 || min > 59 {
    return None
  }
  let s = if sec == 60 { 59 } else { sec }
  if s < 0 || s > 59 {
    return None
  }
  let (month, day) = day_of_year_to_month_day(year, doy)?
  let days = days_from_civil(year, month, day)
  let seconds_of_day = (hour * 3600 + min * 60 + s).to_int64()
  let total_sec = days.to_int64() * 86_400L + seconds_of_day
  let ns = total_sec * 1_000_000_000L + nanos.to_int64()
  Some({ ns })
}

///|
pub fn Time::from_epoch_ns(ns : Int64) -> Time {
  { ns }
}

///|
pub fn Time::to_epoch_ns(self : Time) -> Int64 {
  self.ns
}

///|
pub fn Time::add_ns(self : Time, delta : Int64) -> Time {
  { ns: self.ns + delta }
}

///|
pub fn Time::diff_secs(self : Time, other : Time) -> Double {
  (self.ns - other.ns).to_double() / 1_000_000_000.0
}

///|
/// ISO8601 with microsecond precision, UTC: `2026-08-17T08:30:15.123000Z`.
pub fn Time::to_iso8601(self : Time) -> String {
  let (days, secs_of_day, micros) = self.to_days_secs()
  let (year, month, day) = civil_from_days(days)
  let hour = secs_of_day / 3600
  let min = (secs_of_day % 3600) / 60
  let sec = secs_of_day % 60
  let micro_str = if micros == 0 { "000000" } else { pad_left(micros.to_string(), 6) }
  "\{pad_left(year.to_string(), 4)}-\{pad_left(month.to_string(), 2)}-\{pad_left(day.to_string(), 2)}T\{pad_left(hour.to_string(), 2)}:\{pad_left(min.to_string(), 2)}:\{pad_left(sec.to_string(), 2)}.\{micro_str}Z"
}

///|
fn Time::to_days_secs(self : Time) -> (Int, Int, Int) {
  let whole_secs = self.ns / 1_000_000_000L
  let rem_ns = self.ns % 1_000_000_000L
  let days = Int::from_int64(whole_secs / 86_400L)
  let secs_of_day = Int::from_int64(whole_secs % 86_400L)
  let micros = Int::from_int64(rem_ns / 1_000L)
  (days, secs_of_day, micros)
}

///| Howard Hinnant civil_from_days: days since 1970-01-01 -> (y, m, d).
fn civil_from_days(z : Int) -> (Int, Int, Int) {
  let z = z + 719468
  let era = (if z >= 0 { z } else { z - 146096 }) / 146097
  let doe = z - era * 146097
  let yoe = (doe - doe / 1460 + doe / 36524 - doe / 146096) / 365
  let y = yoe + era * 400
  let doy = doe - (365 * yoe + yoe / 4 - yoe / 100)
  let mp = (5 * doy + 2) / 153
  let d = doy - (153 * mp + 2) / 5 + 1
  let m = if mp < 10 { mp + 3 } else { mp - 9 }
  (if m <= 2 { y + 1 } else { y }, m, d)
}

///| Howard Hinnant days_from_civil: (y, m, d) -> days since 1970-01-01.
fn days_from_civil(y : Int, m : Int, d : Int) -> Int {
  let y = if m <= 2 { y - 1 } else { y }
  let era = if y >= 0 { y } else { y - 399 } / 400
  let yoe = y - era * 400
  let mp = if m > 2 { m - 3 } else { m + 9 }
  let doy = (153 * mp + 2) / 5 + d - 1
  let doe = yoe * 365 + yoe / 4 - yoe / 100 + doy
  era * 146097 + doe - 719468
}

///| day-of-year (1-based) -> (month, day). None when out of range.
fn day_of_year_to_month_day(year : Int, doy : Int) -> (Int, Int)? {
  if doy < 1 || doy > 366 {
    return None
  }
  let leap = (year % 4 == 0 && year % 100 != 0) || year % 400 == 0
  let cum : Array[Int] = if leap {
    [0, 31, 60, 91, 121, 152, 182, 213, 244, 274, 305, 335, 366]
  } else {
    [0, 31, 59, 90, 120, 151, 181, 212, 243, 273, 304, 334, 365]
  }
  let mut month = 1
  while month < 12 && doy > cum[month] {
    month = month + 1
  }
  let day = doy - cum[month - 1]
  Some((month, day))
}

///| Left-pad a string to a target length with '0'.
fn pad_left(s : String, len : Int) -> String {
  if s.length() >= len {
    return s
  }
  let mut out = ""
  let mut i = s.length()
  while i < len {
    out = out + "0"
    i = i + 1
  }
  out + s
}

///|
/// A parsed FDSN Source Identifier: `FDSN:NET_STA_LOC_BAND_SOURCE_SUBSOURCE`.
pub(all) struct SourceIdentifier {
  network : String
  station : String
  location : String
  band : String
  source : String
  subsource : String
} derive(Eq, Debug)

pub fn SourceIdentifier::network(self : SourceIdentifier) -> String { self.network }
pub fn SourceIdentifier::station(self : SourceIdentifier) -> String { self.station }
pub fn SourceIdentifier::location(self : SourceIdentifier) -> String { self.location }
pub fn SourceIdentifier::band(self : SourceIdentifier) -> String { self.band }
pub fn SourceIdentifier::source(self : SourceIdentifier) -> String { self.source }
pub fn SourceIdentifier::subsource(self : SourceIdentifier) -> String { self.subsource }

///|
pub fn SourceIdentifier::to_string(self : SourceIdentifier) -> String {
  "FDSN:\{self.network}_\{self.station}_\{self.location}_\{self.band}_\{self.source}_\{self.subsource}"
}

///|
pub fn parse(input : String) -> Result[SourceIdentifier, SidError] {
  if not input.has_prefix("FDSN:") {
    return Err(SidError::new("missing FDSN: prefix", input))
  }
  let body = input.substring(start=5)
  let parts = body.split("_").to_array()
  if parts.length() > 6 {
    return Err(SidError::new("too many underscore segments", input))
  }
  let fields = fill_parts(parts)
  let network = fields[0]
  let station = fields[1]
  let location = fields[2]
  let band = fields[3]
  let source = fields[4]
  let subsource = fields[5]
  if network.length() == 0 || network.length() > 8 {
    return Err(SidError::new("network must be 1-8 chars", network))
  }
  if station.length() == 0 || station.length() > 8 {
    return Err(SidError::new("station must be 1-8 chars", station))
  }
  if location.length() > 8 {
    return Err(SidError::new("location too long", location))
  }
  if location == "--" {
    return Err(SidError::new("location '--' is forbidden", location))
  }
  if source.length() == 0 || source.length() > 3 {
    return Err(SidError::new("source must be 1-3 chars", source))
  }
  if not valid_chars(network, false) {
    return Err(SidError::new("invalid network chars", network))
  }
  if not valid_chars(station, true) {
    return Err(SidError::new("invalid station chars", station))
  }
  if not valid_chars(location, true) {
    return Err(SidError::new("invalid location chars", location))
  }
  if not valid_chars(band, false) {
    return Err(SidError::new("invalid band chars", band))
  }
  if not valid_chars(source, false) {
    return Err(SidError::new("invalid source chars", source))
  }
  if not valid_chars(subsource, false) {
    return Err(SidError::new("invalid subsource chars", subsource))
  }
  Ok({ network, station, location, band, source, subsource })
}

///| Pad parts (StringView array) to exactly 6 Strings (empty appended).
fn fill_parts(parts : Array[StringView]) -> Array[String] {
  let out : Array[String] = []
  var i = 0
  while i < 6 {
    if i < parts.length() {
      out.push(parts[i].to_owned())
    } else {
      out.push("")
    }
    i = i + 1
  }
  out
}

///| Allowed charset: [A-Z0-9]; station/location additionally allow '-'.
fn valid_chars(s : String, allow_dash : Bool) -> Bool {
  var i = 0
  while i < s.length() {
    let c = s[i]
    if not ((c >= 'A' && c <= 'Z') || (c >= '0' && c <= '9')) {
      if not (allow_dash && c == '-') {
        return false
      }
    }
    i = i + 1
  }
  true

///| CRC-32C (Castagnoli) table for polynomial 0x82F63B78 (reversed).
let crc_table : FixedArray[UInt] = build_crc_table()

///|
fn build_crc_table() -> FixedArray[UInt] {
  let table : FixedArray[UInt] = FixedArray::make(256, 0)
  var i = 0
  while i < 256 {
    var crc : UInt = i.to_uint()
    var bit = 0
    while bit < 8 {
      if crc & 1 == 1 {
        crc = (crc >> 1) ^ 0x82F63B78
      } else {
        crc = crc >> 1
      }
      bit = bit + 1
    }
    table[i] = crc
    i = i + 1
  }
  table
}

///|
pub fn crc32c(data : Bytes) -> UInt {
  var crc : UInt = 0xFFFFFFFF
  var i = 0
  while i < data.length() {
    let idx = (crc ^ data[i].to_uint()) & 0xFF
    crc = crc_table[idx.to_int()] ^ (crc >> 8)
    i = i + 1
  }
  crc ^ 0xFFFFFFFF
}

///|
/// CRC over `data[start..end]`, treating the 4 bytes at `crc_offset` as zeros.
pub fn crc32c_region(data : Bytes, start : Int, end : Int, crc_offset : Int) -> UInt {
  var crc : UInt = 0xFFFFFFFF
  var i = start
  while i < end {
    let byte = if i >= crc_offset && i < crc_offset + 4 { 0 } else { data[i].to_uint() }
    crc = crc_table[((crc ^ byte) & 0xFF).to_int()] ^ (crc >> 8)
    i = i + 1
  }
  crc ^ 0xFFFFFFFF
}

///|
/// Verify the stored CRC of a record spans `raw[start..end]`, CRC field at `crc_offset`.
pub fn verify_crc(raw : Bytes, start : Int, end : Int, crc_offset : Int) -> Bool {
  let stored = @binary.read_uint(raw, crc_offset)
  let computed = crc32c_region(raw, start, end, crc_offset)
  stored == computed
}

pub fn float32_code() -> Int { 4 }
pub fn float64_code() -> Int { 5 }

pub fn steim3_code() -> Int { 19 }
pub fn text_code() -> Int { 0 }

///|
pub fn decode_samples(
  encoding : Int,
  count : UInt,
  payload : Bytes,
) -> Result[Samples, @miniseed3.ParseError] {
  match encoding {
    text_code() => Ok(Raw(payload))
    opaque_code() => Ok(Raw(payload))
    int16_code() => decode_fixed(payload, count, 2, decode_int16)
    int32_code() => decode_fixed(payload, count, 4, decode_int32)
    float32_code() => decode_fixed(payload, count, 4, decode_float32)
    float64_code() => decode_fixed(payload, count, 8, decode_float64)
    _ => Err(@miniseed3.ParseError::UnsupportedEncoding(encoding))
  }
}

fn decode_int16(payload : Bytes, off : Int) -> Double {
  let raw = @binary.read_i16(payload, off)
  raw.to_double()
}

fn decode_int32(payload : Bytes, off : Int) -> Double {
  @binary.read_i32(payload, off).to_double()
}

fn decode_float32(payload : Bytes, off : Int) -> Double {
  @binary.read_f32(payload, off).to_double()
}

fn decode_float64(payload : Bytes, off : Int) -> Double {
  @binary.read_f64(payload, off)
}

fn decode_fixed(
  payload : Bytes,
  count : UInt,
  width : Int,
  read : (Bytes, Int) -> Double,
) -> Result[Samples, @miniseed3.ParseError] {
  let expected = count.to_int() * width
  if payload.length() != expected {
    return Err(@miniseed3.ParseError::BadSampleCount(
      "expected \{expected} bytes for \{count} samples, got \{payload.length()}",
    ))
  }
  let out : Array[Float64] = Array::make(count.to_int(), 0.0)
  var i = 0
  while i < count.to_int() {
    out[i] = read(payload, i * width)
    i = i + 1
  }
  Ok(FloatArray(out))
}

pub fn parse_record(raw : Bytes) -> Result[Record, @miniseed3.ParseError] {
  let h = match @miniseed3.parse_header(raw, 0) {
    Ok(h) => h
    Err(e) => return Err(e)
  }
  let total = total_length(h)
  if total > raw.length() {
    return Err(@miniseed3.ParseError::Truncated(total - raw.length()))
  }
  let sid_start = @miniseed3.fixed_header_size()
  let sid_end = sid_start + h.identifier_length()
  let sid_str = @binary.slice(raw, sid_start, sid_end - sid_start).to_string()
  match @sid.parse(sid_str) {
    Ok(_) => ()
    Err(e) => return Err(@miniseed3.ParseError::BadSid(e.to_string()))
  }
  let extra_start = sid_end
  let extra_raw = @binary.slice(raw, extra_start, h.extra_headers_length()).to_string()
  if extra_raw.trim().length() > 0 && not @json.valid(extra_raw) {
    return Err(@miniseed3.ParseError::MalformedExtraHeaders("invalid JSON"))
  }
  let payload_start = extra_start + h.extra_headers_length()
  let payload = @binary.slice(raw, payload_start, h.payload_length().to_int())
  if not @miniseed3.verify_crc(raw, 0, total, 28) {
    let computed = @miniseed3.crc32c_region(raw, 0, total, 28)
    return Err(@miniseed3.ParseError::BadCrc(computed, h.crc()))
  }
  let start = match @time.Time::from_header(h.time_ns(), h.time_year(), h.time_doy(), h.time_hour(), h.time_min(), h.time_sec()) {
    Some(t) => t
    None => return Err(@miniseed3.ParseError::BadTime("year/doy/hms out of range"))
  }
  let samples = match @encoding.decode_samples(h.encoding(), h.sample_count(), payload) {
    Ok(s) => s
    Err(e) => return Err(e)
  }
  Ok({ header: h, sid: sid_str, extra_headers: extra_raw, samples, start, raw })
}

pub fn iterate_records(raw : Bytes) -> Array[Result[Record, @miniseed3.ParseError]] {
  let out : Array[Result[Record, @miniseed3.ParseError]] = []
  var off = 0
  while off < raw.length() {
    if raw.length() - off < @miniseed3.fixed_header_size() {
      out.push(Err(@miniseed3.ParseError::Truncated(0)))
      break
    }
    match @miniseed3.parse_header(raw, off) {
      Err(e) => {
        out.push(Err(e))
        break
      }
      Ok(h) => {
        let total = @miniseed3.fixed_header_size() + h.identifier_length() + h.extra_headers_length() + h.payload_length().to_int()
        if off + total > raw.length() {
          out.push(Err(@miniseed3.ParseError::Truncated(off + total - raw.length())))
          break
        }
        let rec_bytes = @binary.slice(raw, off, total)
        match parse_record(rec_bytes) {
          Ok(r) => out.push(Ok(r))
          Err(e) => out.push(Err(e))
        }
        off = off + total
      }
    }
  }
  out
}

pub(all) struct SegmentIssue {
  kind : SegmentKind

///|
pub(all) struct SegmentReport {
  gap_count : Int
  overlap_count : Int
  duplicate_count : Int
  rate_change_count : Int
  total_gap_seconds : Double
  issues : Array[SegmentIssue]
} derive(Eq, Debug)

pub fn SegmentReport::gap_count(self) -> Int { self.gap_count }
pub fn SegmentReport::overlap_count(self) -> Int { self.overlap_count }
pub fn SegmentReport::duplicate_count(self) -> Int { self.duplicate_count }
pub fn SegmentReport::rate_change_count(self) -> Int { self.rate_change_count }
pub fn SegmentReport::total_gap_seconds(self) -> Double { self.total_gap_seconds }

///|
pub fn inspect_segments(records : Array[@record.Record]) -> SegmentReport {
  let by_sid : Map[String, Array[@record.Record]] = Map::new()
  for r in records {
    let key = r.sid()
    if by_sid.contains(key) {
      by_sid[key].push(r)
    } else {
      by_sid[key] = [r]
    }
  }
  let mut issues : Array[SegmentIssue] = []
  var gap_secs = 0.0
  let sids = by_sid.keys()
  for sid in sids {
    let group = by_sid[sid]
    group.sort_by_key(fn(r) { r.start_time().to_epoch_ns() })
    var prev : @record.Record? = None
    for cur in group {
      match prev {
        None => ()
        Some(p) => {
          let cur_start = cur.start_time()
          if p.start_time().to_epoch_ns() == cur_start.to_epoch_ns() {
            issues.push({ kind: Duplicate, at: cur_start, detail: "same start time" })
          } else {
            match p.end_time() {
              Some(prev_end) => {
                if cur_start.to_epoch_ns() < prev_end.to_epoch_ns() {
                  issues.push({ kind: Overlap, at: cur_start, detail: "overlaps previous segment" })
                } else {
                  let rate = p.header().rate_hz()
                  if rate > 0.0 {
                    let delta = cur_start.diff_secs(prev_end)
                    if delta > 1.0 / rate {
                      issues.push({ kind: Gap, at: cur_start, detail: "gap of \{format_secs(delta)}" })
                      gap_secs = gap_secs + delta
                    }
                  }
                }
              }
              None => ()
            }
          }
          if p.header().rate_hz() != cur.header().rate_hz() {
            issues.push({ kind: RateChange, at: cur_start, detail: "rate changed" })
          }
        }
      }
      prev = Some(cur)
    }
  }
  var gap_n = 0
  var over_n = 0
  var dup_n = 0
  var rate_n = 0
  for it in issues {
    match it.kind {
      Gap => gap_n = gap_n + 1
      Overlap => over_n = over_n + 1
      Duplicate => dup_n = dup_n + 1
      RateChange => rate_n = rate_n + 1
    }
  }
  { gap_count: gap_n, overlap_count: over_n, duplicate_count: dup_n, rate_change_count: rate_n, total_gap_seconds: gap_secs, issues }
}

fn format_secs(s : Double) -> String {
  if s >= 60.0 {
    "\{(s / 60.0).floor().to_int()}m\{((s % 60.0)).to_int()}s"
  } else {
    "\{s.to_string()}s"
  }
}

///| A single inspection rule.
pub type Rule = (@trace.Trace) -> Array[Issue]

///|
pub fn inspect_trace(trace : @trace.Trace, rules : Array[Rule]) -> QualityReport {
  let mut issues : Array[Issue] = []
  for rule in rules {
    issues = issues.concat(rule(trace))
  }
  let m = compute_metrics(trace)
  { sid: trace.sid(), issues, metrics: m, score: compute_score(m, issues) }
}

fn compute_metrics(trace : @trace.Trace) -> Metrics {
  let samples = trace.samples()
  let n = samples.length()
  if n == 0 {
    return { max_amplitude: 0.0, mean: 0.0, stddev: 0.0, clip_ratio: 0.0, constant_runs: 0, completeness: 1.0 }
  }
  var sum = 0.0
  var max_abs = 0.0
  for v in samples {
    sum = sum + v
    let a = v.abs()
    if a > max_abs { max_abs = a }
  }
  let mean = sum / n.to_double()
  var sumsq = 0.0
  for v in samples {
    let d = v - mean
    sumsq = sumsq + d * d
  }
  var clip = 0
  for v in samples {
    if v.abs() > 0.999 {
      clip = clip + 1
    }
  }
  { max_amplitude: max_abs, mean, stddev: (sumsq / n.to_double()).sqrt(), clip_ratio: clip.to_double() / n.to_double(), constant_runs: count_constant_runs(samples), completeness: 1.0 }
}

fn count_constant_runs(samples : Array[Float64]) -> Int {
  if samples.length() < 2 {
    return 0
  }
  var runs = 0
  var run_len = 1
  var i = 1
  while i < samples.length() {
    if samples[i] == samples[i - 1] {
      run_len = run_len + 1
    } else {
      if run_len >= 10 {
        runs = runs + 1
      }
      run_len = 1
    }
    i = i + 1
  }
  if run_len >= 10 {
    runs = runs + 1
  }
  runs
}

fn compute_score(m : Metrics, issues : Array[Issue]) -> Int {
  var score = 100
  if m.completeness < 1.0 {
    score = score - ((1.0 - m.completeness) * 50.0).floor().to_int()
  }
  for it in issues {
    match it.severity {
      Info => score = score - 1
      Warning => score = score - 5
      Error => score = score - 15
      Critical => score = score - 30
    }
  }
  if score < 0 { 0 } else { score }
}

    if samples.length() < min_run {
      return []
    }

pub fn spike_rule(ratio? : Double = 20.0) -> Rule {
  fn(trace : @trace.Trace) -> Array[Issue] {
    let samples = trace.samples()
    if samples.length() < 3 {
      return []
    }
    var win : Array[Float64] = []
    var spikes = 0
    for v in samples {
      win.push(v.abs())
      if win.length() > 200 {
        ignore(win.pop())
      }
      let scale = rms(win)
      if scale > 0.0 && v.abs() > scale * ratio {
        spikes = spikes + 1
      }
    }
    if spikes > 0 {
      [{ severity: Error, message: "\{spikes} spike(s) detected" }]
    } else {
      []
    }
  }
}

  if win.is_empty() {
    return 0.0
  }
  var sum = 0.0
  for v in win {
    sum = sum + v * v
  }
  (sum / win.length().to_double()).sqrt()
}

  if samples.is_empty() {
    return samples

    out.push(v - m)

///|
pub fn detrend(samples : Array[Float64]) -> Array[Float64] {
  let n = samples.length()
  if n < 2 {
    return samples
  }
  var sx = 0.0
  var sy = 0.0
  var i = 0
  while i < n {
    sx = sx + i.to_double()
    sy = sy + samples[i]
    i = i + 1
  }
  let xbar = sx / n.to_double()
  let ybar = sy / n.to_double()
  var num = 0.0
  var den = 0.0
  i = 0
  while i < n {
    let x = i.to_double()
    num = num + (x - xbar) * (samples[i] - ybar)
    den = den + (x - xbar) * (x - xbar)
    i = i + 1
  }
  let slope = if den > 0.0 { num / den } else { 0.0 }
  let mut out : Array[Float64] = []
  i = 0
  while i < n {
    out.push(samples[i] - (ybar + slope * (i.to_double() - xbar)))
    i = i + 1
  }
  out
}

pub fn hann_taper(samples : Array[Float64], n : Int) -> Array[Float64] {
  if n <= 0 {
    return samples
  }
  let len = samples.length()
  let mut out : Array[Float64] = samples.map(fn(v) { v })
  var i = 0
  while i < n && i < len {
    let w = 0.5 * (1.0 - @math.cos(2.0 * @math.PI * i.to_double() / (2.0 * n.to_double())))
    out[i] = samples[i] * w
    let j = len - 1 - i
    if j >= 0 && j != i {
      out[j] = samples[j] * w
    }
    i = i + 1
  }
  out
}

///|
pub fn sliding_rms(samples : Array[Float64], window : Int) -> Array[Float64] {
  let n = samples.length()
  let mut out : Array[Float64] = Array::make(n, 0.0)
  var i = 0
  while i < n {
    let lo = (i - window).max(0)
    let hi = (i + window + 1).min(n)
    var sum = 0.0
    var k = lo
    while k < hi {
      sum = sum + samples[k] * samples[k]
      k = k + 1
    }
    out[i] = (sum / (hi - lo).to_double()).sqrt()
    i = i + 1
  }
  out
}

    sum = sum + v * v
  }
  sum

///|
pub fn stddev(samples : Array[Float64]) -> Double {
  let n = samples.length()
  if n == 0 {
    return 0.0
  }
  let m = mean(samples)
  var sumsq = 0.0
  for v in samples {
    let d = v - m
    sumsq = sumsq + d * d
  }
  (sumsq / n.to_double()).sqrt()
}

///|
pub fn skewness(samples : Array[Float64]) -> Double {
  let n = samples.length()
  if n < 3 {
    return 0.0
  }
  let m = mean(samples)
  let sd = stddev(samples)
  if sd == 0.0 {
    return 0.0
  }
  var s3 = 0.0
  for v in samples {
    let z = (v - m) / sd
    s3 = s3 + z * z * z
  }
  s3 / n.to_double()
}

///|
pub fn kurtosis(samples : Array[Float64]) -> Double {
  let n = samples.length()
  if n < 4 {
    return 0.0
  }
  let m = mean(samples)
  let sd = stddev(samples)
  if sd == 0.0 {
    return -2.0
  }
  var s4 = 0.0
  for v in samples {
    let z = (v - m) / sd
    s4 = s4 + z * z * z * z
  }
  s4 / n.to_double() - 3.0
}

///|
pub fn resample_basic(samples : Array[Float64], input_rate : Int, output_rate : Int) -> Array[Float64] {
  if output_rate >= input_rate {
    return samples
  }
  let ratio = input_rate.to_double() / output_rate.to_double()
  let n_out = (samples.length().to_double() / ratio).floor().to_int()
  let mut out : Array[Float64] = Array::make(n_out, 0.0)
  var i = 0
  while i < n_out {
    let pos = i.to_double() * ratio
    let i0 = pos.floor().to_int()
    let frac = pos - i0.to_double()
    if i0 + 1 < samples.length() {
      out[i] = samples[i0] * (1.0 - frac) + samples[i0 + 1] * frac
    } else {
      out[i] = samples[i0]
    }
    i = i + 1
  }
  out
}

pub fn recursive_sta_lta(

  sta_len? : Int = 10,

  trigger_on? : Double = 4.0,
  trigger_off? : Double = 1.5,
  min_duration? : Int = 5,
  pad_before? : Int = 10,
  pad_after? : Int = 10,

fn run_trigger(
  samples : Array[Float64],
  sta_len : Int,
  lta_len : Int,
  trigger_on : Double,
  trigger_off : Double,
  min_duration : Int,
  pad_before : Int,
  pad_after : Int,
  ttype : TriggerType,
) -> Array[Event] {
  let ratios = ratio_series(samples, sta_len, lta_len, ttype)
  let n = ratios.length()
  let mut events : Array[Event] = []
  var i = 0
  while i < n {
    if ratios[i] >= trigger_on {
      let start = i
      var end = i
      var peak = ratios[i]
      while end < n && ratios[end] >= trigger_off {
        if ratios[end] > peak { peak = ratios[end] }
        end = end + 1
      }
      if end - start >= min_duration {
        let s = (start - pad_before).max(0)
        let e = (end + pad_after).min(n)
        events.push({ start_index: s, end_index: e, peak_ratio: peak, trigger_type: ttype, confidence: peak_confidence(peak, trigger_on, end - start) })
      }
      i = end
    } else {
      i = i + 1
    }
  }
  events
}

fn ratio_series(samples : Array[Float64], sta_len : Int, lta_len : Int, ttype : TriggerType) -> Array[Float64] {
  let n = samples.length()
  let mut out : Array[Float64] = Array::make(n, 0.0)
  var sta = 0.0
  var lta = 0.0
  var i = 0
  while i < n {
    let v = samples[i].abs()
    match ttype {
      Classic => {
        if i < sta_len {
          sta = (sta * i.to_double() + v) / (i.to_double() + 1.0)
        } else {
          sta = sta + (v - samples[i - sta_len].abs()) / sta_len.to_double()
        }
        if i < lta_len {
          lta = (lta * i.to_double() + v) / (i.to_double() + 1.0)
        } else {
          lta = lta + (v - samples[i - lta_len].abs()) / lta_len.to_double()
        }
      }
      Recursive => {
        sta = sta * (1.0 - 1.0 / sta_len.to_double()) + v / sta_len.to_double()
        lta = lta * (1.0 - 1.0 / lta_len.to_double()) + v / lta_len.to_double()
      }
    }
    out[i] = if lta > 0.0 { sta / lta } else { 0.0 }
    i = i + 1
  }
  out
}

fn peak_confidence(peak : Double, trigger_on : Double, duration : Int) -> Double {
  let ratio_part = ((peak / trigger_on - 1.0).min(2.0)) / 2.0
  let dur_part = (duration.to_double() / 100.0).min(1.0)
  (0.3 * ratio_part + 0.7 * dur_part).min(1.0)
}

fn cmd_convert(path : String, format : String) -> Unit {
  let raw = read_input(path)
  let records = collect_ok(@record.iterate_records(raw))
  let traces = @trace.build_traces(records)

}

///| ASCII waveform, 60 columns.
fn print_waveform(samples : Array[Float64]) -> Unit {
  if samples.is_empty() {
    return
  }
  let peak = @signal.peak(samples)
  if peak <= 0.0 {
    println("(no signal)")
    return
  }
  var i = 0
  while i < samples.length() {
    let v = samples[i] / peak
    let col = (v * 29.0 + 30.0).round().to_int().clamp(min=0, max=59)
    var sb = ""
    var c = 0
    while c < 60 {
      if c == 30 { sb = sb + "|" } else if c == col { sb = sb + "*" } else { sb = sb + " " }
      c = c + 1
    }
    println(sb)
    i = i + 1
  }
}
